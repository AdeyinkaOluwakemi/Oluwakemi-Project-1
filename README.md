# A portfolio website

This project is Adeyinka Oluwakemi Project 1 which is to build a basic portfolio website. It has 6 files which are: The Index file which is the homepage, the CSS file which contains the styling, the about file, contact and projects file, and lastly the images file.
For the contact section I have form that users can fill, to pass whatever information they have for me. To do that , they will be required to include their Names, Emails and their message.
I had a section that contains information to be displayed at the foot of the page.
